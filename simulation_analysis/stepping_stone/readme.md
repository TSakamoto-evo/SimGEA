This folder contains codes for 2D spatial simulation. 

The folder `linkage_equilibrium_simulator` contains C++ simulator code and a python code to run the simulation.  
The folder `slim_code` contains slim code and a python code to run the simulation.  
The folder `env_maps` contains environmental maps used in this study.  
Other codes needed to automate the entire analysis is represented in the folder `codes`.  

The Bash scripts provide example workflows for running the simulations and downstream file processing.
