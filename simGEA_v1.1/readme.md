## SimGEA: A Simulation-Based Framework for GEA Analysis

Each folder contains code for running the analysis.

The `mig_est` folder contains C++ code and requires the Eigen library for compilation.
The `null_simu` folder contains C++ code.

The `executables` folder contains executable files for mac (> v13.0) and windows.
For other environments, please compile the C++ code. 

Please refer to the accompanying manual for details.

This software is provided as is.

Use it at your own risk.
